IdeUltra

A snappy, native, local-first code IDE. Open a folder, edit, save. That's it.

git clone https://github.com/MPJHorner/IdeUltra.git
cd IdeUltra
cargo run --release

Part of the Ultra family — MailboxUltra, PostbinUltra. Pure Rust + egui. Single ~7 MB binary. Zero telemetry. MIT.

Why IdeUltra

Snappy

Cold start under 150ms. Keystroke-to-paint under 16ms. No web stack.

Native

Real macOS window, native folder pickers, native menu bar. No Electron, no webview.

Local-first

Files on disk. State in JSON. No cloud, no telemetry, no sign-in.

Familiar

File tree, tabs, find & replace, syntax highlighting, light/dark. Just the basics, done well.

Watchful

External edits update clean buffers silently. Dirty buffers show a reload banner. Never overwrite by accident.

Session-aware

Quit and relaunch — your folder, tabs, theme, zoom and window all come back.

30-second tour

  1. Press ⇧⌘O to open a folder.
  2. Click a file in the sidebar. It opens in a tab. Click another file — second tab.
  3. Type. Hit ⌘S. The dot in the tab and window title disappears.
  4. Press ⌘F to find. Enter jumps to the next match. ⌥⌘F for find & replace.
  5. Press ⌘G to jump to a line. ⌘B to toggle the sidebar.
  6. Quit. Relaunch. Everything's back.

Use cases

  • Quick edits without booting VS Code. Open a config file, tweak two lines, save, done.
  • Reviewing a downloaded repo. Get instant syntax-highlighted browsing without indexing.
  • Pairing with coding agents. Watch agent edits land in real time via the file watcher.
  • SSH sessions and battery-conscious laptops. A 7 MB binary that doesn't fan-up your machine.

Status

v0.1.0 — Initial MVP release. Ten deliverables (D1–D10), all shipped. See the changelog and the build plan.

macOS unsigned-app note: the v0.1.0 binary is not yet notarised. On first launch macOS will refuse to open it; right-click the app in Finder and choose Open, or run xattr -d com.apple.quarantine /Applications/IdeUltra.app.
